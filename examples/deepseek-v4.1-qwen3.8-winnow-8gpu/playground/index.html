Verified Answers

Every request takes the verified path (model kairyu-verified-always). DeepSeek-V4.1 lists the points the answer must cover and writes the answer; OpenJev checks each point against the answer, then reads those results, the prompt and the answer and decides whether the answer can be adopted as the reply the user expects. The guarantee flag is that adoption decision (its p at or above the threshold); a point marked ✗ is one a repair was asked to fix.
